# 炼金配方编辑器设计备忘

记录日期：2026-10-20。

状态：Godot内的“炼金配置”编辑器已实现，包含配方、物品与素材、类型与通用配置、玩家预览和独立试炼。使用步骤见 [炼金配置编辑器使用说明](alchemy_editor.md)。

炼金玩法规则以 [四槽叙事推理炼金设计](alchemy_experiment_design.md) 为准；当前可运行系统见 [简化炼金系统](alchemy.md)。后续讨论继续更新这两个设计文档。

## 目标

策划可以通过中文表单创建、修改配方和素材，选择图标、数量与产物，并在保存前预览、试炼和检查配置。
正常配置不需要编辑GDScript、手写ItemID引用或打开场景逐个登记配方。

建议在Godot顶部增加“炼金配置”页面，采用主屏幕编辑器插件，给四槽表单和预览留出足够空间。
工具直接保存项目使用的Resource数据，运行时继续复用现有物品、背包与炼金系统。

## 当前项目基础

| 已有内容 | 现状与接入方向 |
| --- | --- |
| `scripts/items/item_data.gd` | 已有ID、名称、图标、说明、单一分类和配方道具关联，继续复用 |
| `scripts/items/item_catalog.gd` | 已有物品目录及初始库存，继续作为唯一物品目录 |
| `data/items/catalog.tres` | 当前物品主要以内嵌Resource保存，不要求第一版全部拆为独立文件 |
| `scripts/alchemy/alchemy_recipe.gd` | 已支持STANDARD兼容模式、EXPERIMENTAL推理模式及A/B/异质数量配置 |
| `scripts/alchemy/ingredient_requirement.gd` | 已分离隐藏答案、公开提示和候选类型；编辑器复用这些字段 |
| `scripts/alchemy/alchemy_system.gd` | 已实现A/B/异质判定、可提交性校验和原子扣除，供后续试炼直接复用 |
| `data/recipes/*.tres` | 配方继续按独立Resource保存 |
| `scenes/AlchemyRoom.tscn` | 已通过recipe_catalog读取统一配方目录；recipes保留为独立演示的覆盖入口 |

现有资源可以由编辑器读取和展示，但不能把旧资源的四个普通需求自动解释为两个明示槽加两个隐藏槽。
例如现有清洗剂要求粉末和三份清水，是否改为新公式需要单独配置，不能因槽位数量相同而自动转换。

## 已确认的玩法约束

- 第1、2槽明确显示素材，且必须正确填满。
- 每个配方固定一种高级公式：前三槽，或全部四槽；基础公式始终是前两槽。
- 只投入前两槽得到A；高级公式完全正确得到B；其他合法的追加素材尝试得到X。
- 高级公式的槽位数量不符仍允许提交。例如四槽公式只填前三槽、三槽公式额外填第四槽，都得到X。
- 玩家界面保留四个槽。第3、4槽使用类型图标，不通过禁用第四槽泄露三槽公式。
- X统一为名叫“异质”的废弃产物。只有少数终极产物把异质作为合成素材。
- 异质产出数量按配方配置，物品种类统一。隐藏槽按提示类型筛选，三槽公式第4槽为“未知素材”，接受任意非配方道具的素材。
- A/B/异质均消耗本次实际投入的全部素材；库存不足、无效物品等验证失败不扣除素材。
- 配方编辑器中的策划可以查看正确答案；玩家预览和实际游戏继续隐藏追加槽答案。

## 界面结构建议

顶部包含“配方”“物品与素材”“类型与通用配置”三个页面入口。

```text
炼金配置    配方 | 物品与素材 | 类型与通用配置
────────────────────────────────────────────────────────
左侧：配置列表       中间：当前配置表单       右侧：预览与试炼
搜索、列表           名称、描述、图标       玩家预览
新建、复制           四个素材槽             公式摘要
状态提示             基础/高级产物          独立背包试炼
                     保存、还原更改
────────────────────────────────────────────────────────
配置检查：具体问题、所在配方、所在槽位，可点击定位
```

静态布局使用`.tscn`场景搭建，样式放入Theme；脚本负责加载数据、事件、校验和保存。
编辑表单优先使用Godot编辑器自身的主题以保证可读性；玩家预览复用`alchemy_theme`和游戏里的展示组件。

## 配方页面

### 列表与基础信息

列表显示图标、配方名称及配置状态，支持按名称或RecipeID搜索、新建和复制。

| 配置项 | 策划操作 |
| --- | --- |
| 配方名称 | 中文文本输入 |
| RecipeID | 新建时生成建议值，首次保存前可调整；已有ID保持稳定 |
| 配方图标 | 从项目中选择或拖入图片 |
| 玩家说明 | 写入配方和背包详情中展示的文字 |
| 策划备注 | 记录推理依据、剧情线索等内部说明，玩家界面不显示 |
| 高级公式 | 明确选择“使用前三槽”或“使用全部四槽” |
| 基础产物A | 从物品目录搜索选择，并填写产出数量 |
| 高级产物B | 从物品目录搜索选择，并填写产出数量 |
| 错误产物X | 显示统一配置的“异质”，本页可修改本配方的产出数量，不提供单独更换物品的入口 |

修改显示名称不修改RecipeID。复制配方生成新的ID，避免两份资源共用同一业务标识。
名称、图标和物品选择都应直接显示结果，物品下拉框使用“图标＋名称＋ID”帮助辨认同名物品。

### 四槽配置

| 槽位 | 策划配置内容 | 玩家看到的内容 |
| --- | --- | --- |
| 第1、2槽 | 精确素材、需要数量 | 具体素材名称、图标和数量 |
| 第3槽 | 类型提示、选料范围、需要数量、正确素材 | 类型提示与数量，不公开正确素材 |
| 第4槽 | 类型提示、选料范围、需要数量；四槽公式另配置正确素材 | 类型提示与数量，不公开是否属于正确高级公式 |

三槽高级公式中的第4槽也保留选料和数量配置；策划表单标注“正确公式不使用此槽”。
它无需填写正确素材，但玩家仍可投入素材，并因此产出异质。

隐藏槽的三个概念必须分开：

1. **类型提示**：向玩家提供哪一种推理提示，以及使用哪个通用图标。
2. **选料范围**：哪些背包物品允许投入，用于生成候选素材列表。
3. **正确答案**：精确的正确ItemID，仅用于提交后的高级公式判定。

不能用“正确答案ItemID”直接筛选候选列表，否则只会显示答案，失去叙事推理的意义。
已确认隐藏槽按提示类型筛选，三槽配方第4槽允许任意非配方道具的素材；编辑器使用现有candidate_category字段配置候选类型。

### 公式摘要

表单根据配置实时显示两条公式和一个统一错误结果。例如下列只是说明结构的占位示例，并非新配方：

```text
基础：素材甲×2 ＋ 素材乙×1 → 成品A×1
高级：素材甲×2 ＋ 素材乙×1 ＋ 素材丙×1 → 成品B×1
追加槽位或素材不匹配 → 异质
```

切换到四槽公式时，高级摘要增加第4槽。摘要显示的是策划视图，玩家预览仍隐藏答案。
从四槽公式切换为三槽公式时，明确提示第4槽将不再参与正确答案判定，玩家仍能选择该槽。

## 物品与素材页面

2026-10-21补充：本页左侧列表增加“全部 / 物品 / 配方道具”筛选，与搜索组合使用；只增加列表筛选，不新增物品种类字段或更改配方关联方式。
“物品”同时包含普通素材、基础/高级产物和异质。某物品可以既是配方的产物，也是另一配方的素材；候选仍按具体ItemID或配置类型检查，不因来源于炼金而排除。
“配方道具”沿用ItemData.alchemy_recipe关联，实际炼金公式继续在“配方”页编辑。切换筛选涉及离开未保存条目时，复用现有保存/放弃/取消提示。

素材、A/B成品、异质和配方道具继续共用ItemData与ItemCatalog。
不新建一套只在编辑器存在的素材数据库，也不为异质创建单独的背包系统。

策划可编辑的最小字段：ItemID、名称、图标、文字说明、单一类型；配方道具额外选择关联配方。
支持在配方的物品选择框旁点击“新建物品”，保存到现有物品目录后返回当前配方继续配置。

类型沿用当前单一category的能力，不引入多重标签、品质或属性系统。
作为素材使用的成品仍是普通物品，少数终极产物可以直接选择异质作为输入。

已有ItemID在第一版保持稳定。删除物品前检查已知配方、配方道具和初始库存引用；被引用时提示具体位置并阻止删除。
场景、脚本或timeline中的字符串引用也可能存在，不能把目录检查视为完整的自动重命名或删除保障。
对已接入剧情的内容，第一版优先编辑名称、描述、图标和配方字段，避免改动既有ID。

初始背包数量仍由`ItemCatalog.initial_inventory`管理，不和“创建素材”混为同一个操作。

## 类型与通用配置页面

建议使用简单的一层类型表，包含类型ID、显示名称和通用图标，例如“植物”“化学品”。
现有物品的category值先保留，由策划明确归类，不根据物品名称自动猜测分类。

类型表用于给物品选择类型、给隐藏槽选择提示图标，并按已确认的规则设置该类型的候选范围。

通用配置选择唯一的异质ItemID，所有错误公式引用它。
异质的产出数量已确认按配方分别配置，使用AlchemyRecipe.waste_result_amount；默认1，必须为正整数。

## 玩家预览与独立试炼

### 玩家预览

右侧展示配方在炼金界面中的公开呈现：前两槽明示，后两槽显示类型图标。
2026-10-21界面调整：移除“背包详情呈现”及其重复说明、素材槽，只保留一组预览。预览素材槽通过继承场景preview_slot.tscn单独调整高度、间距与图标布局。
预览不展示正确答案、策划备注或高级公式使用的真实槽位数量。
三槽公式也显示四个可操作槽，避免在预览阶段就形成答案提示。

### 独立试炼

策划可以配置临时背包、手动填入素材并点击试炼，查看产物和消耗明细。
临时背包使用独立的InventorySystem实例，不调用正在运行游戏中的PlayerInventory、GameProgress或存档接口。

试炼与实际游戏调用同一套AlchemySystem判定，避免编辑器另写一份A/B/异质规则。
每次试炼从临时背包的起始快照开始，显示“验证结果、产物、扣除项、剩余数量”，方便重复比较。

策划至少能够验证以下情况：

| 尝试 | 预期 |
| --- | --- |
| 只填满正确的第1、2槽 | A |
| 精确匹配该配方的高级公式 | B |
| 追加素材错误 | 异质，消耗全部实际投入素材 |
| 四槽公式只填前三槽 | 异质，仍允许提交 |
| 三槽公式额外填第4槽 | 异质，仍允许提交 |
| 基础槽不足、库存不足或ItemID无效 | 不执行，不扣除素材 |
| 异质作为某个终极配方的材料 | 按该配方规则正常校验和消耗 |

试炼中的错误答案可以产生异质；配置检查中的无效ItemID等数据错误需要先修复。

## 保存与校验

编辑时使用工作副本。保存成功后才更新资源，离开未保存的表单时提示处理更改。
第一版建议提供明确的保存按钮与撤销/重做，避免每次输入文字都立即覆盖项目文件。

阻止保存的配置错误至少包括：

- ItemID或RecipeID为空、重复，或引用的物品不存在。
- 素材和产出数量不是有效的正整数。
- 基础槽没有指定素材；高级公式使用的隐藏槽没有指定正确素材。
- 正确素材不在该槽允许的选料范围内。
- 配方缺少A或B，或者通用异质引用无效。
- 必需的类型提示配置无效，导致玩家无法看见约定的类型图标。

三槽公式第4槽没有正确答案是合法配置。它的选料范围和数量仍需有效。
策划备注、叙事线索未填写等内容可提示为警告，不与数据结构错误混淆。

错误应描述具体配方与槽位，例如：“回复药 / 第3槽：正确素材‘熏香草’不在允许的素材类型中。”

保存过程同时涉及物品目录、配方资源及配方目录时，先校验依赖，再提交写入；失败时不能显示“保存成功”或留下指向不存在资源的目录条目。

## 数据与职责建议

以下是实现方向，字段名称在编码时统一，避免此阶段写死为第二套资源格式。

| 部分 | 职责 |
| --- | --- |
| 现有ItemData、ItemCatalog | 唯一物品数据来源；保存素材、成品、异质和配方道具 |
| 简单类型定义 | 保存类型ID、名称、图标，可由ItemCatalog引用，不做多级分类 |
| 扩展AlchemyRecipe与槽位数据 | 保存基础/高级产物、固定高级公式、四槽提示、候选规则与答案 |
| AlchemyCatalog | 统一登记可用配方资源；公共异质继续由唯一ItemCatalog保存 |
| 现有AlchemySystem | 游戏和编辑器试炼共用的验证、A/B/异质判定与合成流程 |
| 编辑器表单 | 中文输入、物品选择、工作副本与错误定位 |
| 编辑器资源保存逻辑 | 调用统一校验，保存现有资源与目录；不负责玩家背包变更 |

已新增`data/recipes/catalog.tres`作为统一目录，由AlchemyUI读取；编辑器保存新配方时同步登记。
物品目录继续使用`data/items/catalog.tres`，不复制另一份物品清单。

配方目录决定项目有哪些配方，GameProgress决定玩家当前解锁了哪些。
配方道具继续通过ItemData.alchemy_recipe关联同一配方资源；实际获得方式由房间或剧情配置，不在保存配方时自动发放。

具体脚本数量以第一版实际需要为准，不提前引入通用表单框架或复杂插件平台。

## 分阶段实施建议

1. **对齐数据与核心规则（已完成）**：已接入两条公式、四槽配置、统一异质和原子消耗。旧配方保留STANDARD模式，新增独立演示配方验证新规则。
2. **完成最小编辑器（已实现）**：配方/物品列表、新建、复制、表单、类型与异质配置、校验、保存并登记目录。
3. **接入玩家预览与独立试炼（已实现）**：复用游戏组件与AlchemySystem，玩家预览不公开隐藏答案，独立试炼复用游戏判定。
4. **完整配置验收（已提供入口）**：可从新建素材开始保存新配方，并在试炼中验证A/B/异质。实际游戏获取仍通过房间或剧情明确配置，不自动发放或解锁。

第一版范围集中在上述闭环。Excel导入导出、批量修改、多语言文本工具、节点式公式编辑、自动生成剧情和复杂属性系统留待另行讨论。
