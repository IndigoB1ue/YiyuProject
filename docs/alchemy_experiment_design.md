# 四槽叙事推理炼金设计备忘

记录日期：2026-10-11。状态：规则已讨论确认，尚未修改现有炼金实现。

## 设计目的

玩家通过剧情、图鉴描述等叙事文本推理配方后两槽的正确素材。
系统预先知道正确的 ItemID；“猜测”是玩家的推理过程，不是随机选择答案或随机决定成功率。
后两槽只用通用类型图标提示，例如植物、化学品，不直接展示正确素材名称或图标。

## 四个槽

- 第1、2槽：明确显示所需素材及数量，属于基础必填槽。
- 第3、4槽：隐藏正确素材，用类型图标占位，属于必须成对使用的补充槽。
- “放满”表示当前槽中选入素材的数量满足配方要求，而不是仅判断槽内是否存在物品。

## 开始炼金的条件

必须先填满第1、2槽。之后只允许两种选择状态：

1. 第3、4槽都完全为空。
2. 第3、4槽都填满素材。

只要第3、4槽中的任一槽选入了素材，就必须将两个槽都填满后才能开始。
只填一个补充槽、任一槽数量不足等状态，开始按钮保持禁用。
开始按钮的可用性只检查选择是否完整、选择是否合法及库存，不提前透露隐藏素材的答案。

## 成品判定

以下判定均以已经满足开始条件并通过最终库存检查为前提：

| 选择情况 | 成品 |
| --- | --- |
| 第1、2槽正确且填满，第3、4槽为空 | A：基础成品 |
| 四槽都填满且正确，包含第3、4槽都匹配预设答案 | B：高级成品 |
| 四槽都填满，但第3、4槽任一素材不匹配预设答案 | X：低级成品 |

等级关系固定为 B > A > X。A、B、X由配方配置为不同成品。
选择不完整时不能开始，不会产生X；库存不足、ItemID无效等技术性验证失败保持背包不变。
填满了错误的隐藏素材属于可提交的尝试，会产出X；不能在选料或开始按钮处提前拦截错误答案。

## 数据与界面约束

- 隐藏槽的类型提示、可放入的素材范围与正确答案需要分开表达。
- 正确素材的ItemID保存在配方数据中，判定由AlchemySystem负责。
- UI只负责类型占位、选择数量、成对填充状态和结果展示。
- 不在选料列表、提示文本、按钮状态或配方详情中提前公开后两槽的准确答案。
- 背包中的配方详情也只能展示前两槽的已知素材和后两槽的类型提示，不能泄露正确素材及其图标。
- 继续复用InventorySystem的原子扣除和成品添加流程。

## 实现前仍需细化

- 各配方第3、4槽的具体正确素材、类型图标及对应叙事线索。
- 隐藏槽是否仅允许同类型素材，或允许选择任意背包素材；目前未进一步确认。
- 建议实际选入的素材全部消耗，包括产出X时的素材；消耗规则尚未单独确认。
- 猜测错误时提供多大程度的反馈，以及成功后是否公开或记录完整配方；尚未确定。
