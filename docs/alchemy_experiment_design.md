# 四槽叙事推理炼金设计备忘

初次记录：2026-10-11。最近确认：2026-10-20。状态：核心规则、类型提示、背包展示及存档恢复已实现，附独立演示场景。

策划配置工具的布局与实现建议记录在 [炼金配方编辑器设计备忘](alchemy_editor_design.md)。

## 设计目的

玩家通过剧情、图鉴描述等叙事文本推理配方后两槽的正确素材。
系统预先知道正确的 ItemID；“猜测”是玩家的推理过程，不是随机选择答案或随机决定成功率。
后两槽只用通用类型图标提示，例如植物、化学品，不直接展示正确素材名称或图标。

## 每个配方的两条公式

- 基础公式固定为：第1槽 + 第2槽 = A。
- 高级公式按配方固定为以下一种：第1槽 + 第2槽 + 第3槽 = B，或第1槽 + 第2槽 + 第3槽 + 第4槽 = B。
- 同一个配方只有一条固定的高级公式，不同时接受三槽、四槽两种正确公式。
- 基础路线产出A；尝试高级路线时，公式正确产出B，公式错误产出X。每次炼金只产出其中一种结果。
- X统一为固定的废弃产物“异质”，不为每个配方分别配置不同种类的失败产物。
- 异质的产出数量由各配方分别配置，必须为正整数；物品种类仍统一。

## 四个槽

- 第1、2槽：明确显示所需素材及数量，属于基础必填槽。
- 第3、4槽：作为追加素材的尝试槽，用类型图标提示，不直接公开高级公式的正确素材。
- 有类型提示的隐藏槽，候选列表按配置的类型筛选，包含该类型的所有可用素材，不按正确答案ItemID筛选。
- 第3、4槽不再要求成对填满；允许只使用其中一槽，也允许同时使用。
- 对于高级公式只需要三槽的配方，第4槽仍允许投入素材，投入后按错误公式产出X，不能通过禁用该槽阻止尝试。
- 三槽高级公式的第4槽固定显示“未知素材”和问号图标，允许投入任意非配方道具的物品；已使用时仍需满足该槽配置的素材数量。
- 配方道具不作为推理炼金的素材。异质和其他成品可作为普通素材使用，前提是满足槽位的候选范围。
- “放满”表示当前槽中选入素材的数量满足配方要求，而不是仅判断槽内是否存在物品。

## 开始炼金的条件

必须先正确填满第1、2槽，并通过物品有效性、允许的选料范围及库存检查。
第3、4槽可以都为空、只使用一槽，或同时使用。
使用的槽位数量是否符合该配方的高级公式，不影响开始按钮的可用性，提交后才判定B或X。
例如，四槽高级公式只填前三槽，或三槽高级公式额外填入第四槽，均允许开始炼金，结果为X。

本次确认的“槽位数量不符”指使用了几个槽位，不等同于单个槽内素材单位数量不足。
已使用槽位的素材数量仍按槽位要求检查；不能利用按钮可用性提前验证隐藏素材是否为正确答案。

## 成品判定

以下判定均以已经满足开始条件并通过最终库存检查为前提：

| 选择情况 | 成品 |
| --- | --- |
| 第1、2槽正确且填满，第3、4槽为空 | A：基础成品 |
| 三槽高级公式：第1、2、3槽正确且填满，第4槽为空 | B：高级成品 |
| 四槽高级公式：第1、2、3、4槽正确且填满 | B：高级成品 |
| 四槽高级公式只填前三槽 | X：异质（废弃产物） |
| 三槽高级公式额外填入第4槽，即使第3槽素材正确 | X：异质（废弃产物） |
| 投入了追加素材，但使用的槽位或素材不符合该配方的高级公式 | X：异质（废弃产物） |

等级关系固定为 B > A > X。A、B由各配方配置为不同成品，X统一使用“异质”。
基础槽未正确填满时不能开始；库存不足、ItemID无效等技术性验证失败保持背包不变。
高级公式的槽位数量不符或隐藏素材错误，属于可提交的尝试，会产出X；不能在选料或开始按钮处提前拦截错误答案。

## 异质与终极产物

- 2026-10-21再次明确：所有普通炼金产物都可以继续作为其他配方的素材，包含A、B与异质；“产物”描述它在某次炼金中的作用，不是禁止再次使用的独立物品种类。仍需满足槽位的ItemID、候选类型、数量及库存要求。
- X的物品名称固定为“异质”，通常作为炼金错误尝试产生的废弃产物。
- 只有少数终极产物的配方需要将异质作为投入素材；并非所有终极产物都需要异质。
- 异质作为普通背包物品保留，供这些配方按需消耗，不因其属于废弃产物而自动销毁。
- 具体哪些终极产物需要异质，以及配方、用量和其他条件，尚待配置。

## 素材消耗

- 无论产出A、B还是X，都消耗本次实际投入的全部素材及对应数量。
- 错误投入的追加素材也会消耗，包括四槽公式缺少追加槽或三槽公式额外投入第4槽时实际选入的素材。
- 未投入的素材不消耗。
- 产出X属于完成一次炼金，不退还素材。
- 库存不足、ItemID无效或其他验证失败时，不执行炼金，背包保持不变。
- 素材扣除与成品加入继续通过InventorySystem的原子交换完成，避免部分扣除后无法添加成品。

## 数据与界面约束

- 隐藏槽的类型提示、可放入的素材范围与正确答案需要分开表达。
- 每个配方的数据保存基础公式、固定的高级公式及A、B成品配置；错误公式统一产出异质，不按配方分别指定失败产物种类。
- 高级公式的槽位及正确素材ItemID保存在配方数据中，判定由AlchemySystem负责。
- UI只负责类型占位、素材选择、数量状态和结果展示，不判断或拦截高级公式的正确性。
- 不在选料列表、提示文本、按钮状态或配方详情中提前公开后两槽的准确答案。
- 背包中的配方详情也只能展示前两槽的已知素材和后两槽的类型提示，不能泄露正确素材及其图标。
- 继续复用InventorySystem的原子扣除和成品添加流程。

## 已落实的资源与运行方式

在Godot中打开 `scenes/AlchemyExperimentDemo.tscn` 并按F6，可以直接体验两份演示配方。
演示使用独立的临时背包和解锁记录，提供所需素材，不改变玩家背包或剧情进度，且不提供正常游戏存档入口。
现有回复药、清洗剂配方保留原来的全部需求与单一产出模式，原有探索和后续剧情继续工作。

| 资源或字段 | 配置职责 |
| --- | --- |
| AlchemyRecipe.formula_mode | STANDARD保留原配方；EXPERIMENTAL启用本设计 |
| ingredients | 推理模式必须配置四个IngredientRequirement |
| result_item_id / result_amount | 基础产物A及数量 |
| advanced_slot_count | 固定高级公式使用3槽或4槽 |
| advanced_result_item_id / advanced_result_amount | 高级产物B及数量 |
| waste_result_amount | 该配方错误尝试产出的异质数量，默认1，可分别修改 |
| IngredientRequirement.item_id | 前两槽的明示素材；高级公式使用的隐藏槽的正确答案 |
| hint_name / hint_icon | 隐藏槽向玩家公开的类型名称、类型图标 |
| candidate_category | 隐藏槽允许选择的ItemData.category，独立于正确答案 |
| ItemCatalog.alchemy_waste_item_id | 所有推理配方共用的异质ItemID，目前为Heterogeneity |

三槽公式的第4槽item_id留空，amount仍可配置；该槽始终按“未知素材”展示并接受任意非配方道具的物品。
候选类型ID继续使用现有单一category字段，没有新增复杂分类逻辑。演示中Herb表示植物类，Mineral表示矿物类。

以下是供开发者验收的演示答案，不会显示在玩家的配方槽或背包详情中：

| 演示配方 | 基础公式 | 固定高级公式 | 错误尝试 |
| --- | --- | --- | --- |
| 调和试作·甲（experiment_three.tres） | 熏香草×1＋清水×1 → 基础试作品×1 | 再在第3槽加入试验叶×1 → 精制试作品×1 | 异质×1 |
| 调和试作·乙（experiment_four.tres） | 熏香草×1＋清水×1 → 基础试作品×1 | 第3槽试验叶×1、第4槽魔力水晶×1 → 精制试作品×1 | 异质×2 |

两份资源已登记在统一配方目录data/recipes/catalog.tres中，AlchemyRoom读取该目录；正式流程仍由GameProgress决定是否解锁，不自动发放演示物品。
如要在正常游戏中试用，可通过现有获取入口或Dialogic Call事件解锁ExperimentThree、ExperimentFour，并通过PlayerInventory发放对应素材。

UI和背包详情共同使用AlchemyRecipe.get_slot_display生成公开展示，隐藏答案只在AlchemySystem提交判定时使用。
存档保留四槽的实际选择，允许保存、恢复错误但合法的追加素材，不提前判定高级公式是否正确。
炼金仍通过InventorySystem.exchange完成一次性扣除和加入，失败时保持背包不变。

回归测试：`tests/alchemy_experiment_test.gd`、`tests/alchemy_experiment_ui_test.gd`。
核心测试覆盖三槽/四槽的组合、混合错误素材、库存变化、容量不足及异质复用；界面测试覆盖公开提示、候选筛选、A/B/异质、存读档和独立演示。

## 后续内容仍需细化

- 各配方第3、4槽的具体正确素材、类型图标及对应叙事线索。
- 正式配方的第4槽选料数量配置；演示资源暂设为1。
- 使用异质的少数终极产物及其具体配方、用量。
- 猜测错误暂显示获得异质及素材已消耗，不提示具体哪个隐藏槽错误；成功后是否公开或记录完整配方尚未确定，本阶段继续隐藏。
