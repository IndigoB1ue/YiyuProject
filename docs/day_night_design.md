# 昼夜与学院互动设计备忘

记录日期：2026-10-11。状态：已讨论，尚未实现。

## 已确定的范围

全局只使用“白天”和“黑夜”两个状态。
昼夜影响两类互动：学生支线剧情，以及素材领取、采集和以物换物。

| 互动 | 白天 | 黑夜 |
| --- | --- | --- |
| 学生支线聊天 | 触发指定为白天的学生支线 | 触发指定为黑夜的学生支线 |
| 学院场所领取素材 | 开放 | 关闭 |
| 学院东、西侧花园采集 | 开放 | 关闭 |
| 黑市以物换物、兑换 | 关闭 | 开放 |

学生支线参考 Momotalk 的个人剧情体验，但入口是玩家在符合时段时找到对应学生并聊天。
每个支线入口配置学生、所需时段、timeline，以及是否已观看的记录，避免重复触发。

## 计划接入方式

- GameProgress 保存全局时段，切换后通知场景更新可互动入口。
- 学生聊天、领取、采集、黑市兑换各自配置允许的时段。
- 界面显示开放状态，实际点击执行前再次检查时段与其他条件。
- 领取和采集继续复用现有 PlayerInventory 和领取记录。
- 黑市兑换配置所需素材及所得物品，复用 InventorySystem.exchange，统一验证库存和容量后提交。
- 阅读 timeline 和查看背包期间保持时段不变。

## 建议与待细化事项

建议通过宿舍床切换时段：白天“休息到晚上”，黑夜“休息到白天”；关键剧情也可以指定时段。
这不是已经接入项目的功能，具体切换入口仍待实现阶段确定。

切换昼夜本身不重置领取记录。
可重复领取和采集的刷新频率、黑市兑换项目与价格、学生支线配置，待后续单独确定。
