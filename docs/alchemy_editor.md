# 炼金配置编辑器使用说明

在 Godot 编辑器顶部点击“炼金配置”，即可配置项目中的配方、物品和素材类型。
如果未看到入口，在“项目 → 项目设置 → 插件”中启用“炼金配置”。

工具直接使用项目已有 Resource，不需要手写 ItemID 引用或修改炼金场景来登记新配方。
规则以 [四槽叙事推理炼金设计](alchemy_experiment_design.md) 为准，设计记录见 [编辑器设计备忘](alchemy_editor_design.md)。

## 页面与保存

- 左侧：搜索、新建、复制、删除配置。
- 中间：策划表单，未保存的输入只修改工作副本。
- 右侧：玩家预览与独立试炼。
- 下方：检查结果，双击问题可以定位到对应配置或字段。

“物品与素材”页面的左侧列表提供“全部 / 物品 / 配方道具”筛选，可以与名称、ID搜索一起使用。
“物品”包括普通素材、炼金产物A/B和异质；“配方道具”指关联了炼金公式的背包物品，公式本身仍在“配方”页编辑。
筛选只改变列表显示，不修改物品数据。当前条目不再符合新筛选时，未保存的更改需要先选择保存、放弃或取消切换；没有匹配项时显示空列表。

玩家预览保留图标、名称、说明和一组素材槽，已移除重复的“背包详情呈现”。预览槽的布局可在 `addons/alchemy_editor/preview_slot.tscn` 中调整，它继承游戏素材槽，单独设置预览高度与间距。

“保存”通过校验后才写入项目。“还原更改”丢弃当前草稿；“撤销 / 重做”可以回退表单修改。
快捷键为 Ctrl+S 保存、Ctrl+Z 撤销、Ctrl+Shift+Z 或 Ctrl+Y 重做；文字输入框内也保留其常规编辑快捷键。
离开有更改的配置前，可选择保存、放弃更改或留在原配置。

已有 ItemID、RecipeID 和已保存类型 ID 保持只读，避免破坏其他资源和剧情引用；显示名称仍可修改。
新建和复制会提供不重复的建议 ID，首次保存前可以调整。

## 先建立物品与类型

1. 在“类型与通用配置”中添加需要的类型，例如“植物”，填写类型名称和通用图标，保存。
2. 在“物品与素材”中点击“新建”，填写名称、说明和图标，选择单一类型，保存。
3. 普通素材与炼金成品使用相同的 ItemData。只有配方道具需要选择“关联配方”；普通素材保持“不关联配方”。

炼金产物可以继续作为其他配方的素材：同一物品可同时是某份配方的产物和另一份配方的输入，A、B与异质都遵循此规则。
基础槽可以直接选择产物的ItemID；隐藏槽按候选类型选择产物，因此要给该产物配置匹配的素材类型。成为产物不会限制它再次参与炼金。

图标可以用“选择图片”从项目中选择，也可以从 Godot 文件系统拖入图片。
物品选择窗口显示图标、名称和 ID，可按名称或 ID 搜索。
配方表单中物品选择旁的“新建物品”会打开独立表单，成功保存后自动填回原字段，原配方草稿会保留。

“类型与通用配置”还负责选择全局统一的异质物品。它必须是名称为“异质”的普通物品。
异质数量由每份推理配方分别配置，不在通用配置中统一固定。

初始背包数量不在创建物品时自动发放，也不由本编辑器的临时背包设置决定。
如需调整游戏初始库存，在文件系统选中 `data/items/catalog.tres`，在 Inspector 中修改 `initial_inventory`。
已保存游戏中的背包继续按存档恢复。

## 配置配方

新建配方默认使用推理模式。已有普通配方仍保留兼容模式，不会自动改变其需求或结果。

### 普通配方

配置全部素材需求和单一产物。可以添加或移除需求，不受四槽限制。
通常选择具体物品；兼容旧需求的类型筛选也会保留。

### 四槽推理配方

填写名称、玩家说明、图标和策划备注，然后配置：

| 字段 | 配置方式 |
| --- | --- |
| 第1、2槽 | 指定具体素材与数量，玩家会看到名称和图标 |
| 第3槽 | 选择公开类型提示，配置允许的候选类型、数量与隐藏正确答案 |
| 第4槽：四槽公式 | 与第3槽相同，需要隐藏正确答案 |
| 第4槽：三槽公式 | 只配置数量；玩家看到“未知素材”和问号，可以投入任意非配方道具素材 |
| 基础产物 A | 选择物品和数量 |
| 高级产物 B | 选择不同于 A 的物品和数量 |
| 异质 | 自动引用全局物品，仅配置本配方的产出数量 |

高级公式固定选择“使用前三槽”或“使用全部四槽”。四槽改为三槽时，需要确认清除第4槽答案，玩家仍可操作第4槽。

隐藏槽的三个概念独立：

- **类型提示**：玩家看到的文字与通用图标。
- **候选范围**：哪些类型的物品可以投入，不能按隐藏答案筛选。
- **正确答案**：策划知道的精确物品，提交后才用来判定 B 或异质。

选择类型会默认填入提示文字、图标和候选类型，可以继续调整提示。隐藏答案必须处在合法候选范围内。
表单的公式摘要属于策划视图，会显示答案；右侧玩家预览不会显示隐藏答案、策划备注或高级公式使用的槽位数量。

## 独立试炼

右侧切换“独立试炼”，设置临时背包数量，选择各槽素材并运行。
每次试炼从同一份临时库存快照开始，复用游戏中的 AlchemySystem，显示验证、产物、消耗和剩余数量。
试炼不会修改 PlayerInventory、游戏进度或玩家存档。

建议至少检查以下组合：

| 投入 | 结果 |
| --- | --- |
| 只填满正确的前两槽 | A |
| 完整匹配固定高级公式 | B |
| 隐藏素材选错 | 异质 |
| 四槽公式只填前三槽 | 异质 |
| 三槽公式额外投入第4槽 | 异质 |
| 已使用槽数量不足、库存不足或物品无效 | 验证失败，不扣除 |

A、B和异质均消耗全部实际投入素材。已使用槽需要满足数量，但额外使用了几个槽不能提前阻止提交。
配方道具不作为推理素材；异质可以像普通物品一样用于少数终极配方。

## 保存后的游戏接入

物品保存到 `data/items/catalog.tres`；新配方保存为独立资源，并自动登记到 `data/recipes/catalog.tres`。
炼金界面读取统一配方目录，无需再到场景手动添加资源。

**登记配方不等于玩家已解锁。** 配方获取仍由现有房间交互、剧情或 GameProgress 配置。
若要制作可收集的配方道具，在“物品与素材”中创建物品并关联这份配方，再为房间或剧情配置获取入口。
编辑器保存资源时不会自动给玩家发放物品或解锁配方。

“检查全部配置”检查目录引用、必填字段、数量、类型、答案和产物等问题。
删除被已知配方、配方道具、初始库存或通用异质配置引用的物品会被阻止，并显示引用位置。
脚本、场景及 timeline 中的字符串引用无法完全自动识别；已接入剧情的 ID 应保持稳定，删除前仍需检查相关内容。
